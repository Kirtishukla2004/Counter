# Countly Counter

A mobile-first React counter with a daily activity timeline. Counter data is saved in the browser's local storage on the device where it is used.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` to preview locally, or `npm run build` to create the production site in `dist/`.

## Publish with GitHub and Vercel

Upload this project folder to a GitHub repository, then import that repository in Vercel. Vercel detects Vite automatically. The build command is `npm run build`, and the output directory is `dist`.

## Data note

This starter stores counts in browser local storage. Each browser/device has its own data; it does not provide account login or cloud synchronization.
